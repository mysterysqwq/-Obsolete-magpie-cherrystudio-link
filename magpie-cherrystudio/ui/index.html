MAGPIE / CHERRY STUDIO

在 Cherry Studio 里使用 Magpie

连接本机网关，把 Magpie 中已启用的模型带到 Cherry Studio。

1

检查连接

自动读取本机 Magpie 端口。也可以填写以 /v1 结尾的地址。

默认标识让 Magpie 把用量记在 cherrystudio 名下；若设置了网关访问限制，请填网关密钥。

正在载入配置…

这里只读取模型列表，不发送聊天请求。

2

导入 Cherry Studio

生成配置后打开 Cherry Studio，在弹出的服务商导入窗口中确认。

服务商类型
OpenAI（Chat Completions）
API 地址

自定义网关密钥只用于本次操作，不写入插件配置。复制的链接和 JSON 包含该密钥。

3

获取模型，开始聊天

  1. 打开 Cherry Studio → 设置 → 模型服务，选择刚导入的 Magpie 并启用。
  2. 点击“管理模型”获取列表，添加需要的模型。不同版本的按钮可能叫“获取”或“添加模型”。
  3. 回到聊天窗口选择模型。Magpie 需要保持运行。

手动添加模型时，请完整保留 ID，例如 provider/model，不要去掉斜杠前的服务商。之后新增模型，在 Cherry Studio 再获取一次列表。

没有弹出导入窗口？

先启动一次 Cherry Studio，让系统注册 cherrystudio:// 协议。如果仍无法打开，在模型服务中手动新增 OpenAI 服务商，使用上面显示的 API 地址和网关 API Key。

此连接器面向同一台电脑上的两个应用；只读 Magpie 端口和模型列表，通过 Cherry Studio 官方导入窗口添加服务商，不修改它的数据库。

↔

让 Magpie 调用 Cherry Studio 的模型

插件也提供 Cherry Studio API Gateway 模型服务商。需要 Cherry Studio 2.x 的 API 网关功能。

  1. 在 Cherry Studio → 设置 → API 网关中点击“启动”，复制网关 API Key。
  2. 在 Magpie → 插件 → 此插件的 Cherry Studio API Gateway 服务商行中“登录”，填写网关地址和密钥。默认地址为 http://127.0.0.1:23333/v1。
  3. 获取模型列表后，在 Magpie 中选择 cherrystudio/服务商:模型 使用。Cherry Studio 需要保持运行。

请选择 Cherry Studio 中直连上游的模型。不要选刚从 Magpie 导入的服务商，否则请求会在两个网关之间循环。
